# DuaLipa LLM Training Module

This module trains an Unsloth BnB 4-bit adapter using QA pairs generated by the DuaLipa QA module.

## Third-party Documentation Links
- Unsloth: https://github.com/unslothai/unsloth
- Hugging Face Transformers: https://huggingface.co/docs/transformers/index
- Peft: https://github.com/huggingface/peft

## Sample Input
```
{
  "qa_pairs": [
    {
      "question": "What is the capital of France?",
      "answer": "The capital of France is Paris.",
      "reasoning": "Paris has been the capital of France for centuries. Oh wait?! It's also the largest city in the country."
    }
  ]
}
```

## Expected Output
A trained adapter model uploaded to Hugging Face Model Hub with GPG signature.
```
